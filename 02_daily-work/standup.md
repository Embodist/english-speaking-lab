# 站会 Stand-up

## 30 秒模板

> Yesterday, I [completed X / investigated Y]. Today, I’ll [do Z]. The main blocker is [blocker], and I need [specific help] from [person/team]. I expect to [deliverable] by [date/time].

## 高频句

- `Yesterday, I worked on the retrieval pipeline.` — 昨天我处理了检索流程。
- `Today, I’ll focus on the evaluation and error analysis.` — 今天重点做评测和错误分析。
- `The implementation is complete, and I’m adding regression tests.` — 实现已完成，正在补回归测试。
- `I’ve made progress on the API integration.` — API 集成有进展。
- `I’m blocked by an issue with the staging environment.` — 被预发布环境的问题卡住了。
- `I’m waiting for the API contract from the platform team.` — 在等平台团队的 API 契约。
- `There are no major blockers at the moment.` — 目前没有重大阻塞。
- `I expect to finish the first version by Thursday.` — 预计周四完成第一版。
- `The scope has changed slightly, so I’m updating the estimate.` — 范围略变，我在更新估算。
- `I found a regression after the latest deployment.` — 最新部署后发现了回归。
- `I’ll share the results once the benchmark finishes.` — 基准测试结束后分享结果。
- `I need another day to validate the edge cases.` — 还需要一天验证边界情况。

## 别说 / 更好地说

| 别说 | 更好地说 |
|---|---|
| `I did many things yesterday.` | `I fixed the parser bug and added tests for empty input.` |
| `It’s almost done.` | `The implementation is done; I still need to finish integration tests.` |
| `I’m blocked.` | `I’m blocked because the staging API returns a 401, and I need the correct service credentials.` |

## 示例

> Yesterday, I finished the first version of the retrieval evaluation script. Today, I’ll compare the baseline with the reranking approach. The main blocker is that the test dataset is still missing a few labels. I’ll sync with the data team and share preliminary results by the end of the day.

## 练习

- [ ] 用真实工作内容填模板，录 30 秒
- [ ] 把 3 个模糊句改成具体句
