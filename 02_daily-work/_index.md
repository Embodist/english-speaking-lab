# 日常工作英语

目标：在站会、澄清需求、报 Bug、PR Review、会议、事故和书面沟通中，**用简单句把信息说全**。

## 笔记

| 场景 | 笔记 | 核心结构 |
|---|---|---|
| 站会 | [[02_daily-work/standup\|Stand-up]] | 昨天 / 今天 / 阻塞 / 预计 |
| Bug 与调试 | [[02_daily-work/bug-report\|Bug 定位]] | 复现 / 日志 / 根因 / 修复 / 测试 |
| PR 与 Review | [[02_daily-work/code-review\|Code Review]] | 建议 / 疑问 / 阻塞 / 非阻塞 |
| 会议 | [[02_daily-work/meeting\|会议发言]] | 观点 / 反对 / 总结 / 行动项 |
| 线上事故 | [[02_daily-work/incident\|事故沟通]] | 影响 / 缓解 / 根因 / 复盘 |
| 邮件与 Slack | [[02_daily-work/email-slack\|书面沟通]] | 请求 / 总结 / 升级 |

## 一周练习安排

- 周一：站会 30 秒模板
- 周二：需求澄清 5 问
- 周三：Bug 口述模板
- 周四：PR 礼貌评论
- 周五：会议总结 + 一封邮件

## 通用原则

1. **先说结论，再补背景**：`The fix is ready; I’m waiting for CI.`
2. **给具体信息**：不要只说 `It’s almost done`，要说还差哪一步。
3. **阻塞项带需求和负责人**：`I’m blocked by X, and I need Y from Z.`
4. **不确定就区分假设与事实**：`I haven’t confirmed the root cause yet.`
5. **书面沟通写行动项**：谁、做什么、何时完成。
