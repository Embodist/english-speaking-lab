# 收集箱

临时存放新句子、想法和待分类内容。**每周清空一次。**

## 规则

1. 新内容先放这里，标 `status/inbox`。
2. 周末分类：句子卡 → `08_sentence-library/` 或主题目录；想法 → 对应主题笔记。
3. 超过两周没处理的条目，删除或合并。
