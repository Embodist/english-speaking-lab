**程序员日常英语沟通大全**

口语 · 会议 · 技术讨论 · Issue / Bug · PR / Code Review · 邮件与书面沟通

定制方向：AI / LLM / Agent 工程师、Python 后端、RAG、多模态与安全工程。

目标：把“看得懂英语”转化为“在真实工作中说得出、写得清、沟通有条理”。

练习法：先跟读，再遮住英文看中文复述，最后替换成自己的真实项目。

# 如何使用本手册

- 每天 30–60 分钟：10 分钟复习短语，15 分钟跟读，15 分钟角色扮演，5–20 分钟写作与纠错。

- 每个场景练三轮：照读；只看中文复述；换成自己实际做过的事情。

- 优先把背景、问题、影响、行动、下一步讲清楚。先准确简洁，再追求高级表达。

- 示例中的业务事实只是示范。项目数据、根因、职责与结果必须基于真实经历。

- 核心沟通框架：Context → Problem → Impact → Action → Next step。

## Issue 口头同步模板

I can reproduce the issue in \_\_\_\_. The expected behavior is \_\_\_\_, but the actual behavior is \_\_\_\_. The impact is \_\_\_\_. I’ve checked \_\_\_\_ and found \_\_\_\_. The root cause is confirmed / still under investigation. Next, I’ll \_\_\_\_.

## 示例 Issue

Title: Search API returns duplicate results when filters are combined  
Environment: staging; Version: vX.Y.Z  
Steps to reproduce: 1) Send a search request with filters A and B. 2) Repeat the request. 3) Compare returned IDs.  
Expected: Each matching record appears once.  
Actual: Some records appear more than once.  
Impact: Clients may display duplicate items.  
Evidence: Request IDs, timestamps, sample payloads, and relevant logs are attached.
