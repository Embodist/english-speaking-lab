# 高频动词与固定搭配

## 开发工作最常用动词

| Verb | 中文 | 常见搭配 |
|---|---|---|
| implement | 实现 | implement a feature / interface |
| integrate | 集成 | integrate with an API |
| refactor | 重构 | refactor the module |
| migrate | 迁移 | migrate the database |
| deploy | 部署 | deploy to staging |
| release | 发布 | release a new version |
| monitor | 监控 | monitor latency and errors |
| investigate | 调查 | investigate a failure |
| reproduce | 复现 | reproduce the bug |
| isolate | 定位/隔离 | isolate the root cause |
| mitigate | 缓解 | mitigate the risk |
| resolve | 解决 | resolve the issue |
| validate | 验证 | validate the input/output |
| verify | 核实 | verify the assumption |
| measure | 测量 | measure p95 latency |
| compare | 比较 | compare two approaches |
| benchmark | 做基准测试 | benchmark the model |
| optimize | 优化 | optimize the hot path |
| document | 记录/编写文档 | document the decision |
| coordinate | 协调 | coordinate with another team |
| prioritize | 排优先级 | prioritize the critical path |
| estimate | 估算 | estimate the effort |
| unblock | 消除阻塞 | unblock the integration |
| deprecate | 弃用 | deprecate the old endpoint |
| enforce | 强制执行 | enforce the policy |
| roll back | 回滚 | roll back the change |
| fall back | 降级/回退 | fall back to a baseline model |

## 高频短语动词

| Phrase | 含义 | 例句 |
|---|---|---|
| look into | 调查 | I’ll look into the timeout issue. |
| figure out | 弄清楚 | We need to figure out why the test is flaky. |
| find out | 查明 | I’ll find out when the API will be ready. |
| follow up | 跟进 | I’ll follow up after the meeting. |
| bring up | 提出话题/问题 | She brought up a concern about latency. |
| point out | 指出 | The reviewer pointed out a missing edge case. |
| roll out | 逐步发布 | We’ll roll out the change to ten percent of traffic. |
| roll back | 回滚 | We rolled back the release. |
| set up | 配置/建立 | I’ll set up the test environment. |
| spin up | 快速启动实例/环境 | We spun up a temporary server. |
| plug in | 接入/插入 | We can plug in a different retriever. |
| take over | 接手 | I’ll take over the on-call shift. |
| hand off | 交接 | I’ll hand off the investigation to the platform team. |
| narrow down | 缩小范围 | We narrowed down the cause to the cache layer. |
| rule out | 排除 | We ruled out a database outage. |
| run into | 遇到问题 | I ran into a dependency conflict. |
| carry out | 执行 | We carried out a load test. |
| cut down on | 减少 | We need to cut down on unnecessary tool calls. |
| scale up | 扩容 | We may need to scale up the inference service. |
| scale down | 缩容 | We can scale down idle workers. |
| kick off | 启动 | Let’s kick off the evaluation. |
| wrap up | 收尾/结束 | I’ll wrap up the migration today. |
| reach out to | 联系 | I’ll reach out to the data team. |
| catch up | 补进度/同步 | Let’s catch up after the release. |
| back up | 备份/支持 | Back up the data before the migration. |
| clean up | 清理 | I’ll clean up the temporary code. |
| work around | 临时绕过 | We found a workaround for the dependency issue. |
| break down | 拆解/故障 | Let’s break down the task into smaller steps. |
| build on | 基于……继续构建 | We can build on the existing RAG pipeline. |

## 适合技术讨论的名词搭配

- root cause analysis — 根因分析
- failure mode — 故障模式
- edge case — 边界情况
- regression test — 回归测试
- backward compatibility — 向后兼容
- breaking change — 不兼容变更
- single point of failure — 单点故障
- source of truth — 事实来源/权威数据源
- end-to-end workflow — 端到端工作流
- request lifecycle — 请求生命周期
- critical path — 关键路径
- operational overhead — 运维开销
- memory footprint — 内存占用
- resource utilization — 资源利用率
- quality degradation — 质量下降
- human review — 人工审核
- rollout plan — 发布计划
- rollback plan — 回滚计划
- acceptance criteria — 验收标准
- action item — 行动项
- open question — 待解决问题
- proof of concept (PoC) — 概念验证
- minimum viable product (MVP) — 最小可行产品
- time to first token (TTFT) — 首 token 时间
- requests per second (RPS) — 每秒请求数
- tokens per second (TPS) — 每秒 token 数
- service-level objective (SLO) — 服务级目标
- service-level agreement (SLA) — 服务级协议
