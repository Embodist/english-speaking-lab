# 日常工作

> 15 条 · 来源：[[09_sources/_index|原始资料]] · 返回 [[08_sentence-library/_index|句子库]]

> [!tip] 用法
> 表格用来筛选和回顾；要逐条掌握，请把目标句复制到 [[10_templates/sentence-card|句子卡]]，配上录音和复习日期。

| # | English | 中文 | 例句 | 提示 |
|---|---|---|---|---|
| 1 | I’m currently blocked by… | 我目前被……阻塞。 | I’m currently blocked by a missing API credential. | 站会 |
| 2 | I’ll share an update after… | 在……之后我会同步进展。 | I’ll share an update after I finish the benchmark. | 进度同步 |
| 3 | Could you review this pull request? | 能否帮忙评审这个 PR？ | Could you review this pull request when you have time? | 代码评审 |
| 4 | I’ve addressed the review comments. | 我已经处理了评审意见。 | I’ve addressed the review comments and pushed an update. | 代码评审 |
| 5 | Could we add a regression test? | 我们能否增加一个回归测试？ | Could we add a regression test for this edge case? | 测试 |
| 6 | The issue is still under investigation. | 问题仍在调查中。 | The root cause is still under investigation. | 故障沟通 |
| 7 | Let’s mitigate the impact first. | 我们先减轻影响。 | Let’s mitigate the impact first, then investigate the root cause. | 故障 |
| 8 | The stack trace points to… | 堆栈跟踪指向…… | The stack trace points to the database layer. | 排障 |
| 9 | Let me make sure I understand correctly. | 让我确认一下我是否理解正确。 | Let me make sure I understand correctly: we need to improve latency without changing the API contract. | 会议 |
| 10 | I’ll follow up after the meeting. | 我会在会后跟进。 | I’ll follow up after the meeting with the benchmark results. | 会议 |
| 11 | What are the next steps? | 下一步是什么？ | What are the next steps, and who owns each task? | 会议 |
| 12 | I need to clarify one requirement. | 我需要澄清一个需求。 | I need to clarify one requirement before finalizing the design. | 会议 |
| 13 | I agree with the direction, but… | 我同意总体方向，但是…… | I agree with the direction, but we should validate the assumption first. | 沟通 |
| 14 | Could we compare the options? | 我们能否比较一下几个方案？ | Could we compare the options based on latency and reliability? | 沟通 |
| 15 | I’ll create a follow-up task. | 我会创建后续任务。 | This is out of scope for now, so I’ll create a follow-up task. | 项目管理 |
