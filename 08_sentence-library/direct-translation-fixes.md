# 中式直译纠正

把“中文思维直译”换成更自然的职场英语。**先记右列，不记错误版本。**

| 常见直译 | 推荐表达 | 说明 |
|---|---|---|
| `I very agree.` | `I completely agree.` / `I agree with that.` | `agree` 不用 very 修饰 |
| `Open the light.` | `Turn on the light.` | 开灯用 turn on |
| `Discuss about the issue.` | `Discuss the issue.` | discuss 直接接宾语 |
| `I will reply you.` | `I’ll get back to you.` / `I’ll reply to your message.` | reply to；get back to 很常用 |
| `Please help me check.` | `Could you take a look?` / `Could you help me check this?` | 工作消息里前者更自然 |
| `I have a question to ask.` | `I have a question.` | 简洁自然 |
| `Today I will report my work.` | `Here’s my update for today.` | 站会常用 update |
| `I made a bug.` | `I introduced a bug.` / `There’s a bug.` | bug 不这样“制造” |
| `The program has a problem.` | `The application is failing.` / `There’s an issue in the service.` | 说具体现象 |
| `I will test it again.` | `I’ll rerun the test.` / `I’ll retest it.` | 更简洁 |
| `I will do it as soon as possible.` | `I’ll take care of it today.` | 给真实时间预期 |
| `I don’t understand what you say.` | `I’m not sure I follow. Could you rephrase that?` | 更礼貌 |
| `How to say ...?` | `How should I phrase this?` / `How do you say ... in English?` | 看语境 |
| `According to my opinion...` | `In my opinion...` / `From my perspective...` | 固定搭配 |
| `There have a problem.` | `There’s a problem.` | There be 结构 |
| `The data are not enough.` | `We don’t have enough data.` | 更自然 |
| `I’m agree.` | `I agree.` | agree 是动词 |
| `Can you explain me?` | `Could you explain it to me?` | explain something to someone |
| `I discussed with him the issue.` | `I discussed the issue with him.` | 常见语序 |
| `This function is used to...`（每句都用） | `This function validates the input and returns...` | 用准确主动动词 |
| `Maybe it is because...` | `One possible reason is...` | 技术解释更清晰 |
