# 1200 句 60 天计划

每天 **20 句**，60 天覆盖全部 1,200 句。每天 20 分钟：听 → 跟读 → 中→英 → 录音。

## 每天固定动作

1. 中→英抽认当天 20 句，3 秒说不出的画 `×`。
2. 只复习昨天和前天画 `×` 的句子。
3. 从当天句子选 3 句，改成你的真实场景并录音。
4. 第 3、7、14 天回看同一批句子；连续 3 次说对才算掌握。
