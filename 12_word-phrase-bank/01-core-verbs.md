# 核心动词（40）

用法：先练 S 级。每个动词按“说 → 写 → 读”各过一遍，见 [[LEARNING-PATH#二、每个词条的三遍法|三遍法]]。

| 级别 | 动词 | 中文 | 说（口语例句） | 写（书面例句） | 读 / 搭配 |
|---|---|---|---|---|---|
| S | implement | 实现 | We implemented bounded retries for transient failures. | This change implements request validation before model calls. | implement a feature / policy; implement … following … |
| S | integrate | 集成 | We integrated the new endpoint into the workflow. | The service integrates with the platform API. | integrate with an API; integrate X into Y |
| A | refactor | 重构 | I refactored the parser before adding the new field. | This PR refactors the retry logic without changing behavior. | a behavior-preserving refactor |
| A | migrate | 迁移 | We migrated the job queue to the new cluster. | The migration moves the database to the new schema. | migrate data; database migration |
| S | deploy | 部署 | We deployed the fix to staging this morning. | The service will be deployed behind a feature flag. | deploy to staging / production |
| A | release | 发布 | We released version 3.2 yesterday. | This release is backward-compatible. | release candidate; release a version |
| A | monitor | 监控 | We’re monitoring error rates after the rollout. | The dashboard monitors latency and resource usage. | monitor metrics; continuous monitoring |
| S | investigate | 调查 | I’m investigating why the job is timing out. | We investigated the failure and narrowed it to the cache. | investigate an issue |
| S | reproduce | 复现 | I can reproduce the bug with an empty payload. | The issue was reproduced in a clean environment. | reproduce a bug; reproducible |
| A | isolate | 隔离 / 定位 | I isolated the problem to the request parser. | We isolated the failing component. | isolate the root cause |
| S | mitigate | 缓解 | We rolled back to mitigate the impact. | A temporary mitigation reduced the error rate. | mitigate the risk / impact |
| S | resolve | 解决 | We resolved the issue by adding a timeout. | The issue was resolved in the latest release. | resolve an issue |
| S | validate | 验证 | We validate the input before calling the model. | The request is validated against the schema. | validate input / output |
| S | verify | 核实 | I verified the fix in staging. | We verified the assumption with a small experiment. | verify the result / assumption |
| A | measure | 测量 | We measured p95 latency under load. | The experiment measures end-to-end latency. | measure performance |
| S | compare | 比较 | Let’s compare both options on the same dataset. | We compared the new pipeline against the baseline. | compare A with B |
| A | benchmark | 做基准测试 | We benchmarked the model on a fixed workload. | The benchmark reports throughput and p95 latency. | run a benchmark |
| A | optimize | 优化 | We optimized the hot path after profiling. | The change optimizes memory usage. | optimize for latency |
| S | document | 记录 / 写文档 | I documented the assumptions in the design doc. | The decision is documented in the RFC. | document a decision |
| A | coordinate | 协调 | I’m coordinating with the platform team. | We coordinated the release across two teams. | coordinate with X |
| S | prioritize | 排优先级 | We need to prioritize the critical path. | The roadmap prioritizes reliability over new features. | prioritize A over B |
| S | estimate | 估算 | I estimate two days for the core flow. | The estimate depends on the migration. | estimate the effort |
| S | unblock | 解除阻塞 | Your change unblocked the integration. | This fix unblocks the downstream service. | unblock the release |
| B | deprecate | 弃用 | We’re deprecating the old endpoint. | The old API is deprecated but still supported. | deprecate an endpoint |
| B | enforce | 强制执行 | We enforce a timeout on every call. | The policy is enforced at the gateway. | enforce a policy |
| S | roll back | 回滚 | We rolled back the deployment immediately. | The rollback restored the previous version. | roll back a release |
| A | fall back | 降级 / 回退 | If the model fails, we fall back to keyword search. | The system falls back to a baseline model. | fall back to X |
| A | maintain | 维护 | We maintain two environments. | The module is maintained by the platform team. | maintain compatibility |
| A | configure | 配置 | We configured the service to use a shorter timeout. | The timeout is configurable. | configure a service |
| B | provision | 预置 / 提供 | We provisioned a new GPU worker. | Resources are provisioned automatically. | provision resources |
| S | debug | 调试 | I’m debugging the flaky test. | The issue was debugged using structured logs. | debug an issue |
| A | trace | 跟踪 | I traced the request through three services. | We traced the failure to a cache miss. | trace a request |
| A | inspect | 检查 | I inspected the logs and found a 401. | The payload is inspected before validation. | inspect the logs |
| B | instrument | 加埋点 | We instrumented the pipeline to measure each stage. | The service is instrumented with metrics and traces. | instrument the code |
| S | narrow down | 缩小范围 | We narrowed it down to the retrieval stage. | The investigation narrowed the cause to the cache layer. | narrow down the cause |
| S | rule out | 排除 | We ruled out a database outage. | The experiment rules out a model-side failure. | rule out a cause |
| S | follow up | 跟进 | I’ll follow up after the meeting. | I’ll follow up with the platform team. | follow up on an action item |
| A | hand off | 交接 | I’m handing off the investigation to on-call. | The incident was handed off to the platform team. | hand off to X |
| S | wrap up | 收尾 | Let’s wrap up the migration today. | We’ll wrap up the release by Friday. | wrap up a task |
| S | reach out | 联系 | I’ll reach out to the data team. | Please reach out if you have questions. | reach out to X |
