# 变换训练

> 看原句，立刻说出变换后的句子。先说，再看答案。

## 陈述→疑问

| 原句 | 变换后 |
|---|---|
| The change broke the build. | Did the change break the build? |
| We rolled back the release. | Did we roll back the release? |
| The latency doubled after the deploy. | Did the latency double after the deploy? |
| The model returns inconsistent results. | Does the model return inconsistent results? |
| They have reproduced the issue. | Have they reproduced the issue? |

## 肯定→否定

| 原句 | 变换后 |
|---|---|
| The tests pass locally. | The tests don't pass locally. |
| We have enough data. | We don't have enough data. |
| The fix is backward-compatible. | The fix isn't backward-compatible. |
| The service is healthy. | The service isn't healthy. |
| I can reproduce it. | I can't reproduce it. |

## 主动→被动

| 原句 | 变换后 |
|---|---|
| The team reviewed the PR. | The PR was reviewed by the team. |
| We deployed the model yesterday. | The model was deployed yesterday. |
| The system rejected the request. | The request was rejected by the system. |
| They fixed the bug in one day. | The bug was fixed in one day. |
| Someone deleted the logs. | The logs were deleted. |

## 直接→礼貌

| 原句 | 变换后 |
|---|---|
| Send me the report. | Could you send me the report? |
| Explain this again. | Could you explain this again? |
| Fix the bug today. | Do you think we could fix the bug today? |
| Change the config. | Would you mind changing the config? |
| Show me the dashboard. | Could you show me the dashboard? |

## 现在→过去

| 原句 | 变换后 |
|---|---|
| The service is down. | The service was down. |
| We are investigating the issue. | We were investigating the issue. |
| The model performs well. | The model performed well. |
| I see the error in the logs. | I saw the error in the logs. |
| The team works on the migration. | The team worked on the migration. |

## 进阶

把原句换成你项目的真实句子，再做同样的变换。
