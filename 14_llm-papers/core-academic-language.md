# 论文核心学术语言（Part 1）

> 来源：[[14_llm-papers/_index#来源与边界|你的论文词汇手册]]。按“先复述、再阅读、后写作”使用。

## 先练这 10 个口头框架

| 框架 | 中文 | 论文场景 |
|---|---|---|
| We propose … | 我们提出…… | Intro / Abstract |
| We introduce … | 我们引入…… | Method |
| We demonstrate that … | 我们证明…… | Results |
| The main contribution is … | 主要贡献是…… | Intro |
| The key idea is to … | 核心思想是…… | Method |
| The results show that … | 结果表明…… | Results |
| This comes at the cost of … | 代价是…… | Discussion |
| One limitation is that … | 一个局限是…… | Limitations |
| To the best of our knowledge, … | 据我们所知…… | Intro |
| We leave … for future work. | 我们留作未来工作…… | Conclusion |

## A1 高频动词（提出 / 展示 / 证明 / 评估）

| 词 | 过去式 | 中文 | abstract 常见搭配 |
|---|---|---|---|
| propose | proposed | 提出（方案/方法） | We propose a framework... |
| introduce | introduced | 引入 | We introduce a new module... |
| present | presented | 呈现；给出 | We present results on... |
| demonstrate | demonstrated | 证明；展示 | We demonstrate that... |
| achieve | achieved | 达到（成绩/效果） | achieve state-of-the-art results |
| outperform | outperformed | 胜过，超过（对手/基线） | outperform prior baselines |
| evaluate | evaluated | 评估，测评 | evaluate on benchmarks |
| benchmark | benchmarked | 做基准测评 | benchmark against ... |
| leverage | leveraged | 利用（借助已有资源） | leverage pretrained models |
| enable | enabled | 使……成为可能 | enable efficient training |
| capture | captured | 捕捉；刻画 | capture long-range dependencies |
