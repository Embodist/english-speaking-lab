# 自我介绍

> 基于真实简历的 30 秒 / 60 秒 / 2 分钟版本见 [[15_resume/self-introduction|简历版自我介绍]]。

## 30 秒版本

> Hi, I’m an AI engineer with a background in Python backend development and cybersecurity. Over the past ten years, I’ve worked on security analytics, NLP-based detection, and LLM-powered applications. My current focus is building agentic workflows for music creation. I’m looking for a role where I can combine AI engineering, system design, and hands-on delivery.

## 60 秒版本

> Hi, I’m an AI engineer with a strong background in Python backend development and cybersecurity. Over the past ten years, I’ve worked on security analytics, NLP-based detection, SOAR orchestration, and LLM-powered applications.
>
> At Tencent Cloud, I worked on LLM-based security triage and an enterprise RAG assistant. That involved document processing, retrieval, reranking, model serving, and integrating AI capabilities into existing systems.
>
> In my current role, I’m focused on multimodal music agents. I use LangGraph and tool calling to coordinate tasks such as pitch analysis, harmony analysis, voice conversion, and audio post-processing. I also pay attention to guardrails, copyright checks, and workflow reliability.
>
> I’m looking for a role where I can combine AI engineering, system design, and hands-on delivery to solve real user problems.

## 结构

1. 现在的身份（AI engineer）
2. 背景（Python backend + cybersecurity）
3. 两个相关项目（security LLM / RAG / music agent）
4. 能力总结（retrieval、orchestration、serving、reliability）
5. 求职方向

## 追问句

- `I can go into more detail about either project.`
- `The project most relevant to this role is …`
- `My contribution was mainly in …`

## 发音重点

| 词 | 要点 |
|---|---|
| cybersecurity | 重音在 **se**curity；词尾 /t/ 轻 |
| orchestration | /ˌɔːrkɪˈstreɪʃən/，重音在 **stra** |
| multimodal | /ˌmaʌltiˈmoʊdl/，重音在 **mo** |
| reliability | /rɪˌlaɪəˈbɪləti/，重音在 **bil** |
| agentic | /eɪˈdʒentɪk/ |
| integrations | 词尾 /z/，不要吞掉 |

## 录制检查

- [ ] 30 秒内说完
- [ ] 包含身份、背景、两个项目、方向
- [ ] 没有逐词背诵感，允许自然停顿
- [ ] 关键词清楚：AI engineer / LLM / RAG / tool calling
- [ ] 录制 3 个版本：慢速清晰 / 正常 / 脱稿
