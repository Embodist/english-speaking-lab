# 后缀 21

> 后缀主要决定**词性**：名词、形容词、动词。先判断词性，再猜含义。

| # | 后缀 | 含义 / 词性 | 例词 |
|---:|---|---|---|
| 001 | **-able/-ible** | 能…的 | readable, flexible, visible |
| 002 | **-al** | 与…有关的 | personal, central, arrival |
| 003 | **-ance/-ence** | 状态/性质 | performance, difference, independence |
| 004 | **-ant/-ent** | 人/物 | assistant, student, dependent |
| 005 | **-ary** | 与…有关的 | temporary, ordinary, dictionary |
| 006 | **-ate** | 使…/做 | activate, calculate, demonstrate |
| 007 | **-er/-or** | 人/工具 | teacher, actor, processor |
| 008 | **-ful** | 充满…的 | useful, careful, powerful |
| 009 | **-ify** | 使…化 | simplify, clarify, classify |
| 010 | **-ion/-tion/-sion** | 动作/状态 | action, creation, decision |
| 011 | **-ism** | 主义/现象 | realism, capitalism, mechanism |
| 012 | **-ist** | 人 | artist, scientist, specialist |
| 013 | **-ity/-ty** | 性质/状态 | quality, security, ability |
| 014 | **-ive** | 有…倾向的 | active, effective, creative |
| 015 | **-ize/-ise** | 使…化 | organize, optimize, modernize |
| 016 | **-less** | 没有…的 | useless, careless, endless |
| 017 | **-ment** | 结果/状态 | development, agreement, improvement |
| 018 | **-ness** | 性质/状态 | happiness, darkness, effectiveness |
| 019 | **-ous/-ious** | 充满…的 | dangerous, curious, obvious |
| 020 | **-ship** | 身份/关系 | friendship, leadership, partnership |
| 021 | **-ward** | 方向 | forward, backward, homeward |

## 练法

看到一个生词，先只看后缀判断词性，再决定它在句子里能不能作主语/谓语/修饰语。
