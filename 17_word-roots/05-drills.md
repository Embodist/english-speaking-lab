## 答案

### A

1. 看（inspect）
2. 引导（conduct）
3. 放置（compose）
4. 写/画（paragraph）
5. 年（annual）
6. 握住（contain）
7. 转（convert）
8. 断（interrupt）
9. 生命（biology）
10. 信任（confidence）
11. 移动（motion）
12. 感受/疾病（sympathy）
13. 名字（nominate）
14. 海（marine）
15. 水（aquarium）

### B

1. aud
2. pos/pon
3. chron
4. tain/ten/tent
5. struct
6. bio
7. cogn/gnos
8. path
9. urb
10. aqua

### C

1. con (一起) + tain (握) → 包含
2. trans (跨) + fer (带) → 传输/转移
3. pre (前) + dict (说) → 预测
4. pro (向前) + ject (扔) → 项目/投射
5. con (一起) + tract (拉) → 合同/收缩
6. trans (跨) + mit (送) → 传输
7. ex (出) + press (压) → 表达
8. sequ (跟随) + ence → 序列
9. gen (产生) + er + ate → 生成
10. optim (最好) + ize → 优化
11. re (回) + posit (放) + ory → 仓库
12. multi (多) + medi (中间) + a → 多媒体
13. an (向) + not (标记) + ate → 标注
14. ag (向) + greg (群) + ate → 聚合
15. authent (真实) + ic + ate → 认证
