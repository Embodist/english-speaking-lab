# 复习日志

每天一份记录，每周一份复盘。**没有记录的练习不算完成。**

## 当前

- [[07_review-log/2026-10-23|2026-10-23 · Day 1 基线]]

## 命名

- 每日：`YYYY-MM-DD.md`
- 每周：`YYYY-Www.md`
- 归档：`archive/`

## 每日记录最少包含

1. 今日场景
2. 3–5 个句子
3. 录音文件名
4. 发现的 1–2 个问题
5. 明天复习内容

## 周复盘最少包含

1. 练习天数与句子数
2. 本周最常犯的 3 个问题
3. 最有效的 5 句
4. 下周重点
