# 发音训练

目标：让**关键词、词尾、重音和节奏**清楚，而不是消除口音。

## 训练优先顺序

| 顺序 | 内容 | 典型对比 |
|---|---|---|
| 1 | 元音 | /ɪ/ vs /iː/（ship/sheep）、/æ/ vs /e/（bad/bed）、/ʊ/ vs /uː/ |
| 2 | 辅音 | /θ/ /ð/（think/this/they）、/v/ vs /w/、/l/ vs /r/ |
| 3 | 词尾 | 复数 -s、过去式 -ed、辅音连缀 |
| 4 | 词重音 | 技术名词不要每个词都同样重 |
| 5 | 连读与弱读 | 实词突出、功能词弱读、按意群停顿 |
| 6 | 数字与缩写 | 版本号、日期、p95、TTFT、SLO |

## 每次练什么

1. 只选 **1 个音 + 1 类词尾**，配 3–5 个技术词和 2 个句子。
2. 先听标准音，再分块跟读，最后整句录音。
3. 检查时只改 1–2 处最影响理解的问题。
4. 把问题记到 [[01_pronunciation/error-notebook|发音错题本]]。

## 自测清单

- [ ] 能区分 ship/sheep、live/leave、bad/bed
- [ ] think / this / they 不会全部说成 /s/ 或 /d/
- [ ] v 与 w 的唇部动作有区别
- [ ] models、tools、tests、scripts 词尾完整
- [ ] fixed、changed、deployed、tested 的 -ed 读法正确
- [ ] 一句话不会每个词都平均用力
- [ ] 复杂句能拆成 2–3 个意群
- [ ] 日期、版本、数字和单位能说清楚
