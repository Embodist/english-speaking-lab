# 最小对立对与词尾

只练**经常说错、且影响理解**的 2–3 对，不要每天把整张表读完。

## 元音对比

| 对比 | 练习词 | 训练提示 |
|---|---|---|
| /ɪ/ vs /iː/ | ship / sheep; live / leave; fill / feel | /iː/ 更长、更紧；/ɪ/ 更短、更放松 |
| /æ/ vs /e/ | bad / bed; man / men; ran / wren | /æ/ 下巴张开更明显；不要都读成中文“诶” |
| /ʊ/ vs /uː/ | full / fool; pull / pool | /ʊ/ 短而放松，/uː/ 更长、更圆唇 |
| /ʌ/ vs /ɑː/ | cut / cot; luck / lock | 美音/英音差异大；先固定一种口音 |
| /ə/ 弱读 | about, support, deployment, problem | 非重读音节要弱，别每个元音都读完整 |

**词对训练**：每对先慢速读 5 次，再放进短句：

- `The ship is ready.` / `The sheep is ready.`
- `I live here.` / `I leave here.`
- `That's bad.` / `That's bed.`

## 辅音对比

| 对比 | 练习词 | 提示 |
|---|---|---|
| /θ/ vs /s/ | think / sink; method / message | 舌尖轻触上下齿之间，气流擦出 |
| /ð/ vs /z/ 或 /d/ | this, that, they, other | 舌尖靠近齿间，声带振动 |
| /v/ vs /w/ | vest / west; vine / wine | /v/ 上齿触下唇；/w/ 双唇圆起，不碰上齿 |
| /r/ vs /l/ | right / light; collect / correct | 英语 /r/ 不弹舌；/l/ 舌尖触上齿龈 |
| /ʃ/ vs /s/ | ship / sip; share / same | /ʃ/ 舌位更靠后，声音更厚 |
| /tʃ/ vs /dʒ/ | cheap / jeep; chain / Jane | 前者清音，后者声带振动 |
| /b/ vs /p/ | bad / pat; bug / pug | 注意清浊与送气 |
| /s/ vs /z/ 词尾 | logs / locks; use / used | 词尾发音会改变听感 |

## 词尾与辅音连缀

高频词：

- `tasks` / `tests` / `scripts` / `requests` / `results`
- `worked` / `fixed` / `deployed` / `changed` / `used`
- `model` / `prompt` / `context` / `request` / `response`
- `first` / `next` / `last` / `risk` / `cost`

三步练：**夸张读出尾辅音 → 正常速度读词组 → 读进句子**。不要在词尾额外加中文式元音。

## 复数 / 第三人称 -s

| 读音 | 示例 | 说明 |
|---|---|---|
| /s/ | tasks, prompts, checks, workflows | 清辅音后 |
| /z/ | logs, models, tools, embeddings | 浊辅音或元音后 |
| /ɪz/ | changes, services, branches | 以 /s/ /z/ /ʃ/ /tʃ/ 等结尾 |

## 过去式 -ed

| 读音 | 示例 | 说明 |
|---|---|---|
| /t/ | fixed, shipped, pushed | 清辅音后；不要加完整 “ed” 音节 |
| /d/ | changed, logged, deployed | 浊音后 |
| /ɪd/ | needed, started, tested | 以 /t/ 或 /d/ 结尾 |

放进真实句子：

- I fixed the bug and pushed the patch.
- We tested the endpoint and deployed the service.
- The request failed, so I checked the logs.
- The model improved, but latency increased.

## 词重音

大写只表示示范重音，不是喊叫：

- We need to **REDUCE LATENCY** without hurting **QUALITY**.
- The issue happens only under **HEAVY LOAD**.
- I tested the **RETRIEVAL PIPELINE**, not just the final answer.
- The main **TRADE-OFF** is accuracy versus response time.
- I haven’t confirmed the **ROOT CAUSE** yet.

## 连读与节奏

- `let me` → 当作一个声音单元
- `kind of` / `sort of` → 弱读表达，正式汇报少用
- `going to` → 先读完整，再练自然速度
- `I’ll check it` / `could you share it` / `have you tried it` → 注意衔接
- `What I mean is…` / `The reason is that…` → 按意群停顿

## 数字、日期、版本

- `fifteen` vs `fifty`；`thirteen` vs `thirty`；`fourteen` vs `forty`
- `point five` (0.5)；`five point two` (5.2)；`two hundred and fifty milliseconds`
- `version three point two`；`Python three point eleven`
- `October twenty-third`；日期口头尽量说月份名称
- 字母拼读：`B as in bravo`、`D as in delta`
- `API` / `SQL` / `RAG` / `SVC`：提前决定读字母还是读单词；第一次说全称
